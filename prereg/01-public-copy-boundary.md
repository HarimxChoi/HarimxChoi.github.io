# Public copy boundary

Public copy is reader-facing communication, not an experiment ledger.

## Required structure

Each project introduction should answer:

1. What problem does it solve?
2. How does it solve the problem?
3. What result or practical value did it produce?

## Separation rule

Evidence ledgers, failed ablations, rejected claims, and unresolved verification items remain internal audit material. They may constrain whether a factual claim is allowed, but their language must not be copied into project cards or articles.

If evidence and the intended public claim conflict, the change pauses for an explicit decision. The copy must not be weakened by inserting an unsolicited caveat.
